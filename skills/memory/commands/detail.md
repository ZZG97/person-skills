# Inspect a Remembered Source

For a journal/item source, pass the exact opaque conversation reference to an
available compatible history Skill or capability. Present the returned content
chronologically or summarize the requested detail.

Do not decode, construct or substitute internal conversation/session/thread IDs.
If the capability is unavailable or the reference is stale, report that limitation
instead of guessing another conversation. File and URL references can be inspected
through the available read tools, within the user's access scope.
