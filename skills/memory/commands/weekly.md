# Weekly Journal Consolidation

Consolidate the completed local calendar week from the Home's daily journal files
into `week-YYYY-Www.md`, using its configured timezone. Read that week's files only;
query history only when an entry needs disambiguation.

Organize around meaningful progress, decisions, lessons and unresolved questions.
Preserve useful source and item references. Describe dated progress; link to the
current item for present disposition and next action. Skip execution noise.

After writing the weekly file successfully, archive its source daily files without
deleting them. Update the journal pointer only if the router already tracks the
latest weekly summary. Run the Home's context renderer when that router changes.
If the week has no source files, report it and do not create an empty summary.
